## 本轮从既有产物补充了什么

对全部 **288 个 Q 条件记录和 240 个实际 S1 trace**，以相同状态的 `f10` 为参照，计算 IMU 联合残差 `d=f11−f10`、`e=f10−GT`：

`MSE(f11,GT)−MSE(f10,GT) = 2 mean(e*d) + mean(d*d)`。

使用保存的 float32 数组转 float64，保留有符号交叉项；没有额外模型调用。对 Q 保留两噪声 replicate，对 trace 保留单条轨迹，不拼成同一统计人口。HumanML263 按现有 motion_process 的 root(4)、RIC(63)、rotation6d(126)、local velocity(66)、contact(4) 分区；分区误差按维数加权后严格还原整体误差，另列 RIC 下肢/躯干头/上肢。**这些是预训练归一化特征 MSE，不是米、物理误差或新的成功指标。**

[完整分解](b0_state_diagnostic_20260928_v1/residual_decomposition.json) 包含528条逐状态记录、逐来源均值和来源等权汇总；[特征分区](b0_state_diagnostic_20260928_v1/feature_partition.json) 绑定本地表示代码。288条 Q 条件 MSE 与02结果全部重算一致。以下仅列两个既定负例的锚点，其他来源、配置、t及静止/倒序/zero/IMU-only等既有条件全部保留。

这里用GT作为同时间索引的固定参考；**它不是自由采样状态的条件期望标签**。不同状态、噪声人口、动作相位和表示分量都会影响误差，不能由上述Q/S1差距单独证明分布偏移、因果机制或物理错误。02对实际动作未完成的审阅结论仍是独立的必要证据。

## 尚缺的最小证据

已有Q在同一个GT噪声状态上具备paired/static/reversed；已有trace则只有各自轨迹的四分支。paired轨迹上的`f10`可以比较同状态文本基线，但**倒序轨迹的f11不能直接当成paired状态的倒序反事实**，两者x_t已不同。

因此仍不能区分：

- 在这些实际状态上，联合响应是否保留输入时间顺序的区分，而不只是相对静止有一个有利或有害偏移；
- 000506即使区分了时间顺序，是否仍停留在相对文本的局部误差改善，未接近完整动作；
- 000382 wrists的同状态有害响应是否也由倒序输入产生，以及误差落在哪些固定特征块。

V只增加缺少的同状态输入对照，同时重放已保存的文本/paired分支作为软件锚点。现阶段不据这些描述性结果指定新损失、时段阈值、残差增益或关节硬mask。

## V：48个状态，一次batch4/状态

唯一权重保持 R final200 `91744ac5a663d5b5279922fdf26e0792bf327bd79ee3eae035e065df8c13a642`。全部 **3 train＋3 development-val × head/wrists × t900/500/250/50＝48** 个状态，来自已完成S1的12条paired轨迹；不按负例、MSE或时段挑选。状态、目标、旧输入和原轨迹身份已在 [proposed_state_groups.json](b0_state_diagnostic_20260928_v1/proposed_state_groups.json) 逐项绑定。

每组读取已有float32 `x_t`，逐位复制为 `[4,263,1,T]`，按固定顺序一次原始MDM前向：

1. **T：text_only**，真实caption，IMU presence=false、严格null，0 encoder调用。
2. **P：paired**，原20Hz输入与原始O[0]静止参考。
3. **S：physical_static**，沿用冻结静止输入/参考。
4. **R：tail_reversed**，沿用冻结的 `[0,T−1,…,1]` 输入变换，参考仍来自原始O[0]。

固定全eval、原归一化、caption、真实长度、mask、时间戳、backbone、环境和浮点类型。每个source/config的caption按原S1的batch1编码一次再复用；P/S/R各进行一次观测/参考编码，缓存跨四个t共享。共 **12×3×2＝72 encoder examples**；第一状态登记6，后三状态登记0。不同来源、配置或变换的缓存身份不得混用。

V输出的是原始分支预测，不调用CFG组合器生成动作。**0次q_sample、0个新噪声、0步posterior更新、0次完整采样、0次训练**；没有“直接f11”的采样快路径，也不把新四分支称为f00/f10/f01/f11的原CFG四分支。预算按48×4＝192个MDM branch examples计，不按48收费。

保存每组4个float32预测、输入状态/target/mask及其身份；可共享已校验的重复数组。全部192分支和48组在启动前登记。连续指标、原始差值、所有负例、failed/not-run均保留；有限但差的结果不改变后续槽位或参数。

## 请02冻结的比较、容差与解释

- **软件锚点**：48组P和T分别与原paired trace的f11/f10比较；同组S/T等式检查。建议沿用`atol=1e−6, rtol=1e−6`，保存bitwise/max/RMS/count，由02执行前正式冻结。模型batch均为4，但分支人口/位置改变；不预先宣称逐位相同，也不在结果出来后放宽界。输入状态、mask、IDs、hash、计数必须精确一致。
- **主要诊断**：固定状态上P−S与P−R的normalized MSE、残差分解和预测距离；五个完整特征分区按维数还原整体，RIC三个子分区另列，不与主分区重复相加。按来源/config/t/train-val分别报告；3来源等权，保留min/max和单例，不跨t合并成一个成功分数。
- **同已有Q并列**：Q先平均两次噪声，V保留单轨迹。可描述P−R在两类状态上的方向差别；Q与V的噪声/状态/轨迹选择不匹配，差值不是受控的状态分布因果效应。不得把V的4个t当作4个独立生成样本。
- **解释分支**：若训练Q的P−R有利、V不再有利，只支持进一步研究实际轨迹上的条件区分；不能直接证明需要续训或新增状态训练。若V仍有利但完整动作缺失，则保留“局部收益不足以完成动作”的结论，不能靠提高gain宣布解决。若拍手的P、R都比S差，则应把不依赖正确顺序的有害响应保留为后续机制问题；也不证明所有IMU输入都应关闭。
- **修正准入**：V不产生新动作，不能评价任何修正是否成功。新时变注入、序列目标、训练状态覆盖或其它修正若提出，须另行给出单一干预、完整配对对照和预算。当前不自动选择任何一项，不把已有粗动作正例或较低feature MSE当认证。

倒序仍是受控输入扰动，不是物理可行的同类实例donor；该检查最多说明本开发面板的时间顺序敏感性，不能升级为严格IMU闭环、相容编辑、泛化或真实设备结论。旧numeric-zero/IMU-only、踢腿返回、右腿保持及训练弓步负例均不删除，只是不为本轮额外生成轨迹。
