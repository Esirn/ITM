# 传感器部位的局部运动：补充评价与下一候选

用户提出“用哪个部位的IMU，就关注哪个部位的轨迹”。本轮据此拆分整体位移与传感器部位局部运动，没有重跑模型、查询GPU、修改旧评价规则或论文，也没有处理用户暂时不看的前端。

## 定义与完成范围

原`head_or_wrists_position_joint_proxy_m`是世界坐标位置误差；原`velocity_joint_proxy_RMSE_m_s`覆盖全22关节。新的补充评价取head关节15或wrists关节20/21，逐帧分别减去预测/GT自身的骨盆位置，再比较位置及20Hz有限差分速度。只去掉根平移，保留原世界轴与朝向，不作旋转/尺度/时间拟合、裁帧或平滑。原全身/根轨迹指标继续保留。

[冻结评价计划v2](sensor_relative_evaluation_20261010_v2/plan.json)绑定完整来源；[完成摘要](../../../outputs/itm_rework/protocol/sensor_relative_evaluation_20261010_v2/summary.json)覆盖20epoch、100epoch unit引导、100epoch textCFG2.5三个阶段的594行，354个不同路径的完整已有输出，5664项第二公式/代数检查，无缺失。重复人口视图/重复引用只计算一次新指标；每片段等权，head/wrists分开，8val主比较、32val简单基线和3train参考不混合。8项指标测试通过，包括随时间整体平移消除、静态平均姿态不能通过动态控制及仅选择传感器关节。

首个CPU入口v1在计算指标前因绝对/相对路径字符串比较失败，并非输入内容变更；旧入口、冻结计划与[失败记录](sensor_relative_evaluation_20261010_v1/failure.json)保留。v2仅修正SHA核验的路径表示问题，结果另存新目录，没有重跑模型。

## 根平移、动态幅度与抖动

逐片段的平方误差有精确分解：传感器关节全局MSE＝根位置MSE＋局部位置MSE＋有符号交叉项。对wrists U100g2.5，片段等权平均分别为6.481807、6.461467、0.048968、−0.028628m²。根位移项占主要量级，但这不是MPJPE的可加百分比，也不能据此认定根轨迹是唯一训练原因。

U100g2.5的wrists时间均值误差RMS为0.106786m、去均值动态误差RMS为0.156486m，MDM分别0.155354/0.299879m。动态项也改善，收益并非只有平均姿态。

另一方面，U的局部jerk head38.422 vs MDM26.012m/s³（+47.71%），wrists190.133 vs91.716（+107.31%），对应GT分别28.513/72.228。它们是关节运动学代理，低jerk不等于动作自然或文本正确。

逐片段预测/GT局部运动幅度比的平均：head空间变化1.635、速度1.542，wrists1.363/1.498。没有全验证集统一收缩，且有过大运动；这不排除个别片段收缩，例如训练参考004728的head速度比0.351、wrists0.394。原弓步行为失败及用户对旧U/F的正面观感仍保留，本轮不赋予新行为成功标签。

20→100epoch unit引导：wrists局部位置0.225381→0.181091，局部速度0.974064→0.775937，但局部jerk102.511→170.576；原全局路径也变差。继续盲加epoch不能替代目标修正。
