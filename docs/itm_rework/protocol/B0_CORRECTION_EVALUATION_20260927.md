1. **静止条件确有非零编码和注入残差。** val static最终E RMS的来源均值head为0.68218、wrists为0.68334；第7层残差RMS分别0.04401/0.04520。各t残差/hidden比例均值分别约0.174–0.175、0.181–0.186（各层/t原量及零分母状态完整保留）。这支持“静止输入并非空控制”的机制事实，不能拆分归因于bias或静止embedding。
2. **历史模型的动态增量在train更明显，val不稳定。** train paired相对static及reversed在四个t、两配置的来源均值MSE均下降；val head相对static约−0.000209到−0.001115，而val wrists反而约+0.000414到+0.001073。val paired−reversed幅度很小，未抵消相对text-only的误差增加。完整encoder/各层residual差异及来源min/max见机器表，不能把差异非零等同于有效控制。
3. **padding上下文会改变有效帧预测，但“padding让误差更坏”不是统一结果。** t=50时，104帧来源000027在配置/条件各格的两噪声均值x0差RMS为0.0371–0.0389；136帧000506为0.00705–0.00842；未新增padding的158帧004728仅约2.48e−7–2.67e−7。t=900时前两者分别0.0501–0.0676、0.0294–0.0563，158帧控制仍约2.52e−7–2.76e−7。若干padded MSE反而更低；各来源/t/条件正负值均保留。因此D确认上下文敏感，不能单独证明旧自由采样退化由padding导致。
