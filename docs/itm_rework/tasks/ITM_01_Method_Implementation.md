## 0. 三个会话共同遵守的协作契约

### 0.1 范围、目标与证据状态

本轮只研究**完整片段输入的离线全身动作生成**，分别使用 `head`（槽位 4）或 `wrists`（槽位 0、1）两种配置。不默认增加 head+wrists 联合配置，不扩展任意佩戴组合，不做在线跟踪、实时系统或未来动作预测。

主场景是**局部表演驱动的虚拟角色动作创作**：用户录制局部运动，并用文本指定最终目标动作或编辑意图；输出不必等于录制时真实发生的完整动作，但应保留输入中实际可观测的惯性特征。文本和 IMU 不预设为严格独立的“语义/物理”变量。

三条主证据是：① IMU 带来文本未确定的实例信息；② 在已确认相容的组合上，文本实现目标编辑且不破坏观测；③ 所提机制在同一 backbone 和明确预算下优于简单替代实现。必须由**同一个最终模型**支撑联合能力，不能拼接不同 checkpoint 的优点。

## 2. M0：先排除会改变结论的实现问题

### M0.1 双腕身份：证明并修复当前信息瓶颈

历史 encoder 顺序为共享线性投影、加传感器 embedding、按有效槽位求均值，再做 temporal Transformer。固定双腕配置时：

\[
h_t=W(s_{L,t}+s_{R,t})/2+b+(e_L+e_R)/2.
\]

所以在 **encoder 接收的归一化特征空间** 交换左右腕，池化 token 不变。逐传感器归一化会影响原始物理读数交换后的数值等价性，测试必须区分两层空间，不能混淆。

**实施：**

1. 固定 eval 模式、同一 mask 和帧序列，编写旧结构左右互换不变的单元测试，保存为 legacy 性质测试。
2. 最小修复优先用固定槽位**有序拼接 + 显式 mask + MLP**。未激活槽位在进入融合前清零，mask 独立输入；保留 head/wrists 两种配置，不扩展复杂图网络。
3. 备选是 pooling 前进行身份与读数的非线性交互。与拼接比较时记录参数量；不要把非线性 pooling 一概假定为信息无损。
4. 保留 legacy 结构和 checkpoint 加载方式；新增 `encoder_variant` 或等效配置，禁止静默改变旧 checkpoint 语义。
5. 新结构测试不仅要求 embedding 改变，还要用非对称输入的短程过拟合和未见动作完整生成，验证左/右动作归属是否改善。

**验收：**身份保持测试通过；旧模型可复现；双腕非对称控制由 02 独立评价。仅“新网络对交换输入产生变化”不是生成控制成功。

### M0.2 关闭条件：gate 必须作用于整个控制残差

历史 adapter 为含 bias 的 Linear。即使 encoder 输出为零，`Adapter(0)=bias`；训练后 null 路径未必等于原始 MDM。零初始化时等价、head-null=wrists-null，都不能证明训练后保留原始 Text-only 路径。

**先审计 checkpoint，不先推定影响大小。** 同一 `x_t,t,caption` 比较：原始 MDM、完全 bypass adapter、当前 `imu_uncond`、有效 mask 的数值零输入、按契约构造的物理静止输入。报告单步最大/相对差、若干完整采样差及 adapter bias 范数。

**修复要求：**

- 明确 `condition_present[B]` 或等价门控，对**每层完整 residual**（包括 bias）生效；不要只 gate encoder 输出。
- IMU dropout 也关闭整个 residual；独立采样文本和 IMU dropout，并记录有效组合频次。
- cached control 必须携带相同 presence 信息；顺序、batched CFG 与未缓存执行一致。
- 前置 text/timestep token 是否受控制残差影响必须明确；历史补零 token 仍可能受到 adapter bias，不能把它当自然 bypass。
- 无有效 sensor、force-uncond、部分 batch 样本关闭、全部关闭等情况不能产生 NaN 或旧 control 状态泄漏。
- 原始 MDM 权重、eval 状态、标准化和 sampler 一致时，关闭控制应在说明的数值容差内还原原始输出。容差由 dtype/设备验证，不事后放宽掩盖错误。
- 对旧 checkpoint 保留 `legacy_null` 等显式复现模式；新 checkpoint/run 使用新 schema 与模型版本，不能把修复后结果冒充旧方法原样复现。

数值零 IMU 只作网络诊断。全零 3×3 矩阵不是合法静止姿态；物理静止输入由 02 按单位与坐标约定生成。

### M0.3 时间、padding、缓存和冻结状态

历史 IMU temporal encoder 没有显式时间位置编码；但 MDM 端有时间位置机制，因此不能声称整个模型没有时序能力。

- 在控制编码中增加基于物理时间的明确位置输入，保留无位置消融。时间反转、移位、时长变化的测试区分条件敏感性与正确跟随。
- 修改 padding 的数值、batch 搭配、无效帧长度，不应改变有效帧输出（正常数值容差与无随机 dropout 前提下）。分别测试 encoder 和完整 MDM；若原始 MDM 本身就有 batch/长度依赖，先记录来源，不归因于新模块。
- forward hook/临时 `control` 缓存在异常退出、连续不同 batch 和空条件调用后必须清理，避免跨请求污染。
- 冻结参数不等于关闭 dropout。审计 `model.train()` 是否使冻结 MDM 的 dropout 开启，以及 teacher/student 比较是否混入不同随机模式。采用何种策略都要固定并公开，避免续训过程悄悄改变。
- teacher eval / `no_grad` 不能影响 student 恢复后的模块训练状态；参数 `requires_grad`、优化器参数清单和 checkpoint 内容用测试核对。
- 固定初始噪声不足以控制随机 DDPM 后续噪声。与 02 对齐完整采样随机流，在所有条件分支间重放同一随机计划。

### M0.4 训练目标和数据语义

与 02 一起核对，但数据文件仍由 02 修改：

- 历史标准输入是世界系安装顶点运动学加速度和全局姿态，不是原始机体系加速度计比力；禁止在模型端自行改变其含义。
- 历史 active trajectory loss 对恢复后的全局关节监督，主 tracking 指标却是 root-relative。将两种损失/评价显式命名，并独立消融；不能在表中统称“IMU loss”。
- GT 关节监督允许用于训练，但其约束可能比输入 IMU 更强。区分“配对动作拟合正则”和“测量一致性损失”。
- 速度、加速度、jerk 使用固定时间单位；差分和有效掩码覆盖整个 stencil。固定 FPS 下未除 dt 的历史损失可保留，但必须版本化，不直接拿同权重跨 FPS。
- 原始 jerk 正则可能只惩罚超过 GT 的部分；记录实际公式，不用泛称“物理约束”。过度收缩/静止不能作为成功。
- IMU dropout 后，哪些辅助项仍生效要明确；相容编辑样本不得一边换目标文本，一边继续用原始完整动作监督所有自由部位。

### 3.2 四分支 CFG 契约

令 `f00/f10/f01/f11` 分别表示无条件、仅文本、仅 IMU、文本+IMU：

\[
f=f_{00}+w_t(f_{10}-f_{00})+w_s(f_{01}-f_{00})
+w_i(f_{11}-f_{10}-f_{01}+f_{00}).
\]

这是效应分解，不是统计独立或物理解耦的证明。旧三分支公式作为 `legacy` 保留，但不将其“关闭 text main effect”直接解释成严格 IMU-only。

测试 `w_s=w_i=0` 的 Text-only、`w_t=w_i=0` 的 IMU-only，以及所有权重为 1 时还原 `f11`；这些恒等式还依赖 null 分支实际正确。任意标量或逐样本 scale 均要保持 batch 语义一致。测试 `sequential / batched / cached`，并记录前向次数和额外计算。

提供实际可运行的训练和采样 CLI、配置样例、checkpoint 格式、输出 motion/FK/时间信息、失败与超长片段处理，以及 paired/shuffled/null 的条件注入方式。以下是建议逻辑接口，不是假定现有函数已经存在：


`condition` 引用契约化的文本、IMU、mask、时间、标定；`sampling_spec` 明确 sampler、steps、guidance_mode 和三个 scale、随机计划。模型输出不得复制目标 IMU 作为“生成观测”；观测由 02 的算子从同一输出运动独立重算。

## 4. M2-B：相容条件下的语义相对响应保留

建议分支：`method/semantic-response`。这是首选研究探索，不是已验证方案。

### 4.1 机制假设

绝对 Text-only anchor 把 teacher 某一次动作实例的几何结构压给条件模型，可能与 IMU 冲突。相比之下，保留文本从 `c0` 改为 `c1` 时的**相对语义响应**，可能保留编辑性而不强迫复制 teacher 的完整动作。

### 4.2 样本与 teacher

02 提供仅来自训练分组的 `(s,c0,c1,compatibility_evidence,attribute_spec)`，每个组合有已声明的相容性依据。teacher 是冻结的原始 Text-only MDM；不能是存在 null bias 的“伪原始”分支。

对 teacher 和 student，在同一模型噪声空间内使用成对随机计划或同一 `x_t,t`。不同 backbone 不共享未定义的 latent noise。

\[
x_i^\theta=G_\theta(c_i,s,z),\quad x_i^0=G_0(c_i,z),
\]
\[
\Delta_\theta=\Phi(x_1^\theta)-\Phi(x_0^\theta),\quad
\Delta_0=\Phi(x_1^0)-\Phi(x_0^0).
\]

首个实现用可解释属性的方向或有界 margin；精确幅度匹配作为消融：

\[
\mathcal L_{resp}=w_{compat}\,d\!\left(\Delta_\theta,
\operatorname{stopgrad}(\Delta_0)\right).
\]

`Phi` 可以是部位表示或可微的运动属性，不使用未经检查的全身逐点姿态距离替代。速度/步幅等 teacher 本身不可靠的属性，不强制蒸馏错误方向。

teacher 置信筛选只能由训练/验证规则确定；记录覆盖率及被排除原因。最终测试不按 teacher 或 student 是否成功过滤；确需报告 teacher-capable 子集，必须事先固定并同时报告全体结果。

### 4.3 联合训练约束

- 原始配对数据继续进行标准 diffusion 训练，避免只学手工文本模板。
- 两个编辑输出都计算已验证观测残差；若只有 joint proxy，实验与损失名称明确带 proxy，不冒充严格传感器约束。
- 编辑后未变的观测可以监督；原始全身 GT 不能继续约束所有被允许改变的成分。有动作见证时使用正确对应目标，而不是错误原配对目标。
- student 两个条件支路使用一致 dropout/随机控制；编辑支路的目标文本和 IMU 必须实际启用。teacher 不更新。
- 先实现单步 `x0` 预测或少步可微确定性 rollout，验证梯度、显存和完整生成效果；单步采用 GT 加噪时注意几何泄露使任务过易，记录 timestep 分层表现。
- 只有完整采样有验证收益，才增加 rollout 步数或监督复杂度。不能把 InfoNCE 检索率或 denoising loss 下降直接当作联合控制改善。

### 4.4 消融与验收

同一 B0 起点比较：无 anchor、既有 absolute anchor、relative response、relative response + compatibility weighting。额外 teacher 前向/缓存成本单列；既比较固定更新次数，也提供成本视角，不能声称所有方案“同算力”而忽略 teacher。

进入最终评价的条件：在预先冻结的小验证面板上，**相同观测误差预算下的语义成功和联合成功提升**；独立属性评价/盲评也支持；完整采样和未见模板/原始动作组上成立；运动幅度与自然度不过度恶化。

停止或返工：仅训练 Phi 改善；靠更大 IMU 误差提升语义；靠筛除失败样本；teacher 才是主要效果来源而简单替代同样有效；只在单步预测有效。

## 5. M2-C：观测敏感性的语义更新约束

建议分支：`method/observation-aware-guidance`。优先级低于 B，依赖 02 的输出观测闭环认证。

### 5.1 启动门槛

02 交付 `ObservationOperator`、已验证观测通道、GT round-trip 和可微一致性测试。在此之前最多实现接口与 proxy 实验，不写“精确物理解耦”。若输出表示无法恢复必要旋转，先报告障碍，不另接独立 IMU head 或复制输入以绕过。

### 5.2 局部方案

在与实际可渲染输出一致的运动学变量 `q` 中，令归一化残差 `r=O(q)-s`（旋转用相应流形残差），`J=dr/dq`，语义方向为同一切空间的 `v_text`：

\[
P_\lambda(v)=v-J^\top(JJ^\top+\lambda I)^{-1}Jv,
\quad
\delta_s=-J^\top(JJ^\top+\lambda I)^{-1}r.
\]

以 `delta_s + P_lambda(v_text)` 为局部提案。说明 `v_text` 如何由同一状态下的文本预测差映射到 `q`；不能直接把任意冗余 263D 通道差当一致的关节切空间方向。

使用 JVP/VJP、阻尼 CG 或合适的小块求解，不显式构建整段动作的大矩阵；加入步长/信赖域限制、旋转 retraction、失败回退和每次更新后实际非线性残差复查。`lambda>0` 时只是软约束投影，不声称更新精确处于零空间。

如果只在最终动作后处理，明确命名为后处理；如果在去噪中应用，说明怎样将更新运动重新编码为合法 backbone 表示，以及哪些通道需要同步。不要修改一个关节通道却让位置、旋转、速度和接触互相矛盾。

### 5.3 必要比较和失败条件

先做最简单的可微观测损失梯度引导，再比较敏感性方案与固定 CFG。测量额外算子调用、前向/反向、CG 次数、时延/峰值显存，不能仅按 diffusion step 数量称等预算。

成功要求：相容组合的语义—观测权衡优于普通梯度引导；输入噪声和小标定偏差下不放大抖动；同一输出 FK 与多通道表示自一致；没有通过全部运动趋于静止来满足约束。

停止条件：观测残差本身不可信；仅 joint proxy 改善而姿态严重失真；求解成本不可接受；验证曲线未优于普通梯度基线。DDNM、逆问题投影和现有动作空间引导需由 03 查证相关工作，不将通用公式声称为首次提出。

## 6. B/C 合并与不做清单

先分别取得相对 B0 的可复现收益，再做 `B0 / B / C / B+C` 的 2×2 组合。B 是训练约束，C 是采样/动作更新机制，两者可能互补，也可能没有额外价值；未证实的模块删除而不是凑成多模块故事。

暂不做：新的大型 backbone 迁移、任意传感器图、六传感器联合主任务、实时 demo、完整动力学求解器、没有评价闭环的更多 loss、仅为扩大参数量的全模型微调。若新证据表明这些成为必要依赖，先提出成本与替代路线，而非自行扩张范围。
