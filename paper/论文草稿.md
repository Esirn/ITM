# ITM: 面向文本到动作生成的稀疏 IMU 控制

## Abstract

文本到人体动作生成（Text-to-Motion）近年来取得了显著进展，能够根据自然语言描述生成语义合理的人体动作。然而，文本描述往往是模糊的：同一句 “a person walks” 可以对应不同的步速、步频、路径、身体摆动和个体运动风格。另一方面，稀疏 IMU 传感器可以提供真实身体运动的时序线索，但在传感器数量很少时，仅依赖 IMU 难以恢复完整动作语义，尤其难以决定未观测身体部位的运动。本文研究 IMU-guided Text-to-Motion Generation：在预训练文本到动作生成模型的基础上，引入少量 IMU 读数作为控制条件，使生成动作同时满足文本语义与稀疏传感器约束。我们基于官方 HumanML3D MDM 模型构建一个冻结生成骨干，新增稀疏 IMU 时序编码器，并通过零初始化 residual adapters 将 IMU 控制信号注入 MDM Transformer。该设计保留 MDM 的文本生成能力，同时以较低训练成本学习 IMU 控制。我们构建 HumanML3D/AMASS 到标准虚拟 IMU 的数据桥，并设计同文本换 IMU、同 IMU 换文本、Text/IMU 交叉矩阵等反事实实验协议。初步实验表明，IMU 能在文本模糊时改变生成动作的轨迹、步频和运动细节；文本也能在 head-only IMU 条件下影响摆臂和行走风格。然而，当前 stage-1 模型仍存在 jerk 偏高、正式生成指标和 IMU consistency 指标未完全补齐等问题。本文因此将当前结果定位为一个可行性充分的初稿基础，而非最终投稿版结论。

## 1. Introduction

人体动作生成是连接自然语言理解、人体运动建模和虚拟角色控制的重要问题。Text-to-Motion 模型允许用户通过自然语言描述生成动作，例如 “a person walks forward and turns left” 或 “a person sits down”。这类方法降低了动画创作和动作编辑门槛，在游戏、影视、VR/AR、数字人和机器人仿真等场景中具有广泛潜力。

然而，文本描述本身具有强烈的欠定性。用户输入 “a person walks” 时，文本并不指定具体步速、步频、转向、身体晃动、手臂摆动或个体运动习惯。因此，纯文本生成模型虽然可以产生合理动作，却很难根据用户真实身体状态或传感器读数进行具体控制。对于需要个性化动作、实时身体控制或低成本动作捕捉的场景，这种模糊性会成为明显限制。

与此相对，IMU 传感器能够记录身体局部的加速度和方向信息。现有 sparse-IMU pose estimation 方法，如 TransPose、DIP、IMUPoser 或 MobilePoser 类方法，主要目标是从少量 IMU 恢复人体姿态。它们通常以 MPJPE、旋转误差、foot skating 等指标评价，适合姿态重建任务。但当传感器数量很少时，例如只有头部 IMU，传感器本身并不足以决定手臂、腿部和全身动作语义。IMU-only 模型容易产生过平滑动作，或者在未观测部位缺乏合理语义补全。

本文的基本假设是：文本和 IMU 在动作生成中承担互补角色。文本提供高层语义和全身动作先验，IMU 提供局部、连续、个体化的时序控制信号。我们希望生成模型既能响应文本意图，又能遵循真实或虚拟 IMU 所包含的运动细节。换言之，ITM 研究的不是“用文本辅助 IMU 姿态估计”，而是“用 IMU 控制预训练文本到动作生成模型”。

为此，我们提出一个基于 MDM 的 IMU 控制框架。我们冻结官方 HumanML3D MDM 和 CLIP 文本编码器，新增一个稀疏 IMU encoder，并在 MDM Transformer 的每层后添加零初始化线性 residual adapters。该结构借鉴 ControlNet 的零初始化控制思想，但不是完整 ControlNet：它不复制 MDM backbone，也不引入 cross-attention，而是在冻结生成骨干内部进行轻量残差注入。训练时只优化 IMU encoder 和 adapters，因此训练成本较低，并且初始化时模型行为与原始 MDM 完全一致。

本文当前贡献可以概括为：

1. 定义并实现 IMU-guided Text-to-Motion Generation 任务，将少量 IMU 作为文本动作生成模型的控制条件。
2. 构建 HumanML3D/AMASS 到标准虚拟 IMU 的数据桥，支持 head-only 和 wrists 等稀疏传感器配置。
3. 提出 Frozen MDM + Sparse IMU Control Adapters 的轻量融合方法，支持独立 text guidance 和 IMU guidance。
4. 设计反事实实验协议，包括同文本换 IMU、同 IMU 换文本、Text/IMU 交叉矩阵，用于分析文本和 IMU 是否真正互补。
5. 通过初步 test split 实验验证两个核心现象：IMU 可在模糊文本下改变运动细节，文本可在 head-only IMU 下影响摆臂和行走风格。

需要强调的是，当前工作已经足以启动论文撰写，但仍不足以作为最终投稿版本。主要原因是 stage-1 模型尚未加入显式 IMU consistency、velocity 或 jerk 正则，导致生成动作稳定性仍需提升；同时 official HumanML3D text generation metrics 和正式 IMU consistency metrics 仍需补齐。

## 2. Related Works

### 2.1 光学动捕与 IMU 动作重建

传统高质量人体动作捕捉依赖多相机光学系统或专业动捕设备，能够获得准确的全身姿态，但成本高、部署复杂、场景受限。相比之下，IMU 传感器体积小、成本低、可穿戴，适合移动环境和日常场景。DIP、TransPose、IMUPoser、MobilePoser 等工作研究从少量 IMU 恢复人体姿态，常使用 root-relative MPJPE、rotation geodesic error、foot skating、jitter 等指标评价。

这些方法的核心目标通常是姿态估计或动作重建，即从 IMU 输入恢复与 ground truth 尽可能接近的姿态序列。ITM 与它们的边界在于：ITM 不把任务定义为唯一姿态重建，而是将 IMU 作为生成模型的控制条件。对于同一文本，ITM 希望不同 IMU 产生不同但合理的动作；对于同一 IMU，ITM 希望不同文本能补全或编辑未观测身体语义。

### 2.2 文本到动作生成

Text-to-Motion 工作从自然语言生成动作序列，常见模型包括 MotionDiffuse、MDM、MotionGPT、T2M-GPT 等。MDM 将扩散模型引入人体动作生成，并在 HumanML3D 上使用 Matching Score、R-precision、FID、Diversity、Multimodality 等指标评价文本匹配、生成质量和多样性。

纯 Text-to-Motion 的优势是语义生成能力强，但缺少外部物理控制信号。同一句文本可以产生大量动作，这既是多样性的来源，也是可控性的限制。ITM 继承 MDM 的动作生成先验，同时引入 IMU 作为时序控制，使生成动作不仅“像文本描述的动作”，也能“像某个传感器轨迹对应的动作”。

### 2.3 多条件控制生成

可控动作生成研究使用轨迹、关键帧、接触、物体、音乐、场景或其他条件控制生成结果。OmniControl、ControlNet 风格扩散控制等方法表明，将额外条件注入预训练生成模型可以实现更强的可控性。

ITM 与这类工作的联系在于都关注生成模型的可控性；区别在于 ITM 的控制信号来自 wearable IMU，即 acceleration 和 orientation 的连续时序信号，而不是人工指定的轨迹点或离散控制标签。当前实现借鉴 ControlNet 的零初始化 residual 思想，但采用轻量 adapters 而非复制完整生成 backbone。

### 2.4 多模态 egocentric motion 与 Ego4o

Ego4o 等工作关注第一视角、多模态输入与人体动作之间的关系，对 ITM 的多模态建模有参考意义。但 ITM 当前不使用第一视角视频，也不试图复现完整 Ego4o pipeline。本文将 Ego4o 视为相关多模态思路，而非直接 baseline。ITM 的核心输入是 text + sparse IMU，核心输出是 HumanML3D-style full-body motion。

## 3. Method

### 3.1 Problem Formulation

给定文本描述 $c$、稀疏 IMU 序列 $s$、传感器有效 mask $m$，目标是生成动作序列 $x$。文本描述动作语义，IMU 提供局部身体部位的时序控制。与传统重建不同，$x$ 不一定被视为唯一 ground truth，而是在满足语义和控制约束下的合理生成样本。

当前 motion 表示采用 HumanML3D 263D representation，生成后通过 `recover_from_ric` 恢复 22 个 joints。IMU 表示为 6 个固定槽位，每个槽位每帧包含 3D acceleration 和 3x3 orientation，共 12D。

### 3.2 Standard Virtual IMU Bridge

我们通过 HumanML3D `index.csv` 将 HumanML3D motion 映射回 AMASS/SMPL 序列，并从 SMPL/AMASS 生成标准虚拟 IMU。缓存频率为 30 FPS，训练和采样时重采样到 MDM 的 20 FPS。Acceleration 使用线性插值，orientation 使用 Slerp。每个 IMU 序列保留 6 个固定槽位：

| Slot | Part |
| ---: | --- |
| 0 | Left Wrist |
| 1 | Right Wrist |
| 2 | Left Thigh |
| 3 | Right Thigh |
| 4 | Head |
| 5 | Pelvis |

当前融合模型训练使用两种配置：head-only，即 slot 4；wrists，即 slots 0 和 1。数据规模为 7009 train、434 val、1333 test aligned records。

### 3.3 Frozen MDM Backbone

我们使用官方 MDM HumanML3D checkpoint `humanml_trans_enc_512/model000475000.pt`。该模型使用 CLIP ViT-B/32 编码文本，Transformer latent width 为 512，包含 8 层 Transformer Encoder，diffusion steps 为 1000，最大序列长度为 196 frames。当前工作冻结 MDM 和 CLIP，不更新其参数。

冻结 MDM 的目的有三点。第一，保留官方模型已经学到的文本到动作生成先验。第二，降低训练成本，使实验可在单卡上快速迭代。第三，保证初始化时 Text-only 路径与官方 MDM 一致，便于分析 IMU 控制是否真正产生增量作用。

### 3.4 Sparse IMU Encoder

IMU encoder 输入为：

```text
B x T x 6 x 12
```

每个 12D sensor feature 先通过共享线性层投影到 512D，并加入可学习 sensor embedding。随后使用 sensor mask 在传感器维度做 masked mean pooling，得到每帧一个 512D token。该序列再输入 2 层、8 heads 的 temporal Transformer Encoder，得到 IMU control feature：

```text
C_imu in R^{B x T x 512}
```

当前方法在时序编码前进行多传感器 pooling。这使实现简洁并支持可变 sensor mask，但也可能削弱不同传感器之间的显式交互，是后续改进方向。

### 3.5 Zero-initialized Residual Adapters

我们在 MDM 的 8 个 Transformer layer 后分别添加一个零初始化线性 adapter：

```text
H_l = MDMTransformerLayer_l(H_{l-1})
H_l = H_l + ZeroLinear_l(C_imu)
```

每层 adapter 独立，不共享参数。由于 adapter 权重和 bias 都初始化为 0，初始模型与原始 MDM 完全等价。训练过程中，IMU encoder 学习提取控制特征，adapter 学习将这些特征注入不同层的 motion tokens。

需要注意的是，MDM 内部序列包含一个 text/timestep condition token 和 T 个 motion tokens，而 IMU 只对应 T 个时间帧。因此我们在 control sequence 前补一个 zero token，使其与 MDM 的 T+1 token 对齐。

### 3.6 Training Objective

当前 stage-1 训练使用官方 MDM diffusion loss，即 predicted x_start reconstruction loss。训练时文本条件和 IMU 条件独立 dropout：

- text dropout probability: 0.1。
- IMU dropout probability: 0.1。

训练超参数如下：

| Item | Value |
| --- | --- |
| Training records | 7009 |
| Sensor configs | head, wrists |
| Epochs | 5 |
| Batch size | 16 |
| Optimizer | AdamW |
| Learning rate | 1e-4 |
| Gradient clipping | 1.0 |
| Frozen modules | MDM, CLIP |
| Trainable modules | IMU encoder, 8 adapters |

五个 epoch 的 loss 为：

```text
0.07791, 0.08080, 0.07893, 0.07619, 0.07642
```

当前没有加入显式 IMU consistency、velocity consistency、joint trajectory、foot contact 或 physics loss。这是当前模型 jerk 偏高的主要可能原因。

### 3.7 Independent Guidance

推理时我们使用三分支 guidance：

```text
output =
    unconditional
    + text_scale * (text_only - unconditional)
    + imu_scale  * (text_imu - text_only)
```

这使得 Text-only、IMU-only diagnostic、Text+IMU 可以通过同一个模型和同一组噪声比较。反事实实验中所有条件共享 diffusion initial noise，以确保可见差异来自条件变化，而不是随机噪声变化。

## 4. Experiments

### 4.1 Datasets

实验使用 HumanML3D/AMASS 对齐数据。HumanML3D 提供文本和 263D motion；AMASS/SMPL 提供生成标准虚拟 IMU 所需的身体运动。当前标准 IMU cache 包含：

| Split | Records |
| --- | ---: |
| Train | 7009 |
| Val | 434 |
| Test | 1333 |

早期 sanity baseline 使用 999/200/200 的 train/val/test 子集，用于验证数据流、回归 baseline 和 sparse sensor ablation。

### 4.2 Metrics

本文当前使用三类指标。

第一类是 Text-to-Motion 官方指标，最终论文应重点补齐：

| Metric | Meaning |
| --- | --- |
| Matching Score | 文本与动作 embedding 距离，越低越好 |
| R-precision | 文本-动作检索 top-k 准确率，越高越好 |
| FID | 生成动作分布与真实分布距离，越低越好 |
| Diversity | 生成动作整体多样性 |
| Multimodality | 同一文本下多样本差异 |

第二类是当前 counterfactual suite 使用的 proxy 指标：

| Metric | Meaning |
| --- | --- |
| active_sensor_trajectory_error_m | 当前传感器对应 joint 的 root-relative trajectory error |
| head_trajectory_error_m | head joint 轨迹误差 |
| wrist_trajectory_error_m | wrists 轨迹误差 |
| root_relative_motion_error_m | 全身 root-relative joint error |
| jerk_ratio | 生成 jerk / GT jerk |
| arm_swing_proxy_m | wrist-relative-to-shoulder motion amplitude |
| root_travel_m | root 水平位移 |
| step_frequency_hz | foot speed frequency proxy |

第三类是 IMU-only baseline 指标，包括 root-relative MPJPE、rotation geodesic error、jerk ratio 和 foot skating。这类指标适合 IMU pose estimation，不应作为 ITM 的唯一主指标。

### 4.3 Early Reconstruction Baselines

早期线性 baseline 表明，synthetic IMU-heavy 输入在 deterministic reconstruction 中很强，而文本特征帮助有限。999 train / 200 test 上，IMU-only linear baseline 的 test MSE 为 0.024277，text-only 为 0.062518。

Frame-level MLP 在 999 train / 200 val 上进一步降低 IMU-only eval MSE 到 0.014230，但加入 hashed text 后 eval MSE 反而恶化到 0.020078。这说明简单文本表示容易记忆训练集，不等于文本语义真正有用。

Temporal Transformer + DistilBERT 将文本换成预训练 embedding，并加入序列建模，但在 6 sensors 条件下，IMU-only test MSE 为 0.018271，DistilBERT+IMU 为 0.018774，文本仍未改善。这提示：在强 IMU 和 deterministic MSE 目标下，文本难以发挥作用。

### 4.4 Sparse Sensor Ablation

稀疏传感器实验显示，文本价值依赖传感器位置和欠定程度。在 wrists 配置下，DistilBERT+IMU 相比 IMU-only 同时改善 test MSE 和 MAE：

| Sensors | Text | Test MSE | Test MAE |
| --- | --- | ---: | ---: |
| wrists | no | 0.030797 | 0.098079 |
| wrists | yes | 0.029610 | 0.096633 |

但 head-only 的验证集改善没有在 test 上复现；6 sensors 仍 favor IMU-only。这说明旧回归任务并不适合作为最终 formulation，也促使我们转向生成式 MDM backbone。

### 4.5 Text-only MDM Baseline

我们接入官方 MDM checkpoint 作为合格 Text-only baseline。官方 20-rep reference log 报告：

| Metric | Value |
| --- | ---: |
| FID | 0.5443 |
| R-precision top-1 | 0.3195 |
| R-precision top-2 | 0.4978 |
| R-precision top-3 | 0.6110 |
| Diversity | 9.5595 |

当前项目已经完成 MDM wrapper 和 smoke visualization，但尚未完成 ITM 的 full official MDM evaluation。

### 4.6 IMU-only Baseline

Flexible IMUPoser baseline 使用 2-layer 512-wide bidirectional LSTM，输出 24 SMPL joint rotations in 6D，并支持 flexible sensor mask。604 train / 115 val 上：

| Configuration | MPJPE | Rotation error | Jerk ratio | Foot skating |
| --- | ---: | ---: | ---: | ---: |
| head | 14.75 cm | 0.275 rad | 0.314 | 0.142 m/s |
| wrists | 10.59 cm | 0.233 rad | 0.408 | 0.324 m/s |

Wrists 已通过初步 12 cm 门槛；head-only 尚未通过。该 baseline 仍需增强，尤其是 head-only 场景。

### 4.7 MDM IMU Control Pilot

在训练集和初始 unseen-test pilot 中，stage-1 ITM 已出现互补信号。同文本换 IMU 时，head IMU 产生 15.9-20.1 cm 的 root-relative joint differences。固定 head IMU 时，训练样例中 arm-swing caption 将 arm swing proxy 从 0.155 m 提升到 0.298 m。但初始 test pilot 中该现象不稳定，因此需要系统实验。

### 4.8 Counterfactual Suite on Test Split

我们在 test split 上完成 60 个 run、770 个 generated cases。输出位于：

```text
outputs/mdm_control/experiments/
```

#### Same Text, Different IMU

固定文本：

```text
a person walks
```

对 30 个 test samples 生成 MDM Text-only、ITM Text+head IMU、ITM Text+wrist IMUs。

| Group | Active sensor error | Jerk ratio | Arm swing | Root travel |
| --- | ---: | ---: | ---: | ---: |
| all | 0.2871 m | 4.2072 | 0.1909 m | 2.1561 m |
| head | 0.1733 m | 4.5210 | 0.2021 m | 2.1826 m |
| wrists | 0.5147 m | 3.5796 | 0.1686 m | 2.1030 m |

结果表明，同一句模糊文本下更换 IMU 会改变 root travel、step frequency 和 full-body motion proxies。这支持 IMU 提供具体运动约束的假设。但 jerk ratio 偏高，说明生成稳定性不足。

#### Same Head IMU, Different Text

固定 head-only IMU，使用 6 条 walking prompts。Prompt-level 结果如下：

| Prompt | Head error | Arm swing | Jerk | Root travel |
| --- | ---: | ---: | ---: | ---: |
| walking with swinging arms | 0.1662 m | 0.2615 m | 6.2430 | 3.3377 m |
| walking quickly | 0.1824 m | 0.2304 m | 5.6510 | 2.4707 m |
| turning while walking | 0.2088 m | 0.2153 m | 4.1204 | 1.4661 m |
| walking | 0.1731 m | 0.2088 m | 5.1645 | 2.4170 m |
| walking slowly | 0.1776 m | 0.1742 m | 4.1510 | 2.1081 m |
| walking with large steps | 0.1948 m | 0.1582 m | 3.7824 | 1.8873 m |

Arm-swing prompt 的 arm swing proxy 最高，同时 head error 保持较低。这比初始单样本 pilot 更支持文本补全未观测身体语义的假设。不过，该 prompt 的 jerk 也最高，说明语义增强和动作平滑之间存在 trade-off。

#### Guidance Sweep

扫描：

```text
text_scale in {1.0, 2.5, 4.0}
imu_scale  in {0.5, 1.0, 2.0}
sensor     in {head, wrists}
```

当前推荐：

| Sensor | Text scale | IMU scale | Active sensor error | Jerk |
| --- | ---: | ---: | ---: | ---: |
| head | 2.5 | 0.5 | 0.2003 m | 1.6134 |
| wrists | 2.5 | 0.5 | 0.4794 m | 1.5036 |
| wrists | 2.5 | 1.0 | 0.4847 m | 1.5066 |

#### Matrix Experiment

Matrix 实验随机选择 20 组 A/B test samples，对 head 和 wrists 分别生成 Text/IMU 的 8 种非空组合，并展示 Ground Truth A/B。该实验主要用于定性分析：

- Text A + IMU B 是否表现为 A 的语义与 B 的运动细节。
- Text B + IMU A 是否出现可解释反事实变化。
- Text-only 是否保持 MDM 语义能力。
- IMU-only diagnostic 是否提供轨迹/节奏但语义不足。

## 5. Discussion

当前结果支持 ITM 的基本可行性。首先，同文本换 IMU 的实验显示，IMU 条件确实能改变生成动作的具体运动属性。其次，同 head IMU 换文本的实验显示，文本可以影响未被头部传感器直接观测的上肢运动。第三，guidance sweep 表明 text_scale 和 imu_scale 存在可调 trade-off，且较小的 imu_scale 往往能降低 jerk。

但当前方法仍有明显限制。最主要的问题是 temporal stability。Stage-1 模型只使用 MDM diffusion loss，没有显式 IMU consistency 或 smoothness loss，因此在部分条件下 jerk ratio 明显偏高。其次，当前 control metric 仍是基于 joints 的 proxy，还不是严格 generated motion -> virtual IMU 的 acceleration/orientation consistency。再次，Text-to-Motion 官方指标尚未对 ITM 输出完整评估，因此还不能声称 Text+IMU 在保持 MDM 文本质量和多样性的同时显著提升控制一致性。

因此，当前版本适合支撑论文初稿和方法叙述，但不适合直接作为最终投稿实验。下一阶段应保持当前 frozen MDM adapter 框架，加入 active sensor trajectory consistency、velocity consistency 和 jerk regularization，优先解决动作稳定性问题。

## 6. Conclusion

本文提出并初步验证了 IMU-guided Text-to-Motion Generation 任务。与纯 Text-to-Motion 不同，ITM 允许稀疏 IMU 控制同一文本下的具体运动细节；与 IMU pose estimation 不同，ITM 关注生成空间中的语义补全和多条件控制。我们基于冻结 MDM 和轻量 IMU residual adapters 构建模型，并通过 HumanML3D/AMASS 标准虚拟 IMU 数据桥完成训练和测试。反事实实验表明，当前模型已经能体现文本与 IMU 的互补作用，但仍需进一步降低 jerk、补齐官方生成指标和正式 IMU consistency 指标。

当前进展足以启动论文撰写，尤其是 introduction、related work、problem formulation、method 和 preliminary experiments；但最终投稿前还需要第二阶段模型改进和更完整的定量评估。
